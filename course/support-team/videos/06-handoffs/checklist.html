The next agent asks for the code again
Verified is per call and travels with it. If it asks again, check that each agent's prompt says to trust a code already checked on this call.
Transfer to a person fails
Check MY_PHONE_NUMBER is in +1 format and the account can place calls.
The handoff is declined
Agent-to-agent handoffs need all three agents on the same voice provider, Grok or OpenAI. Gemini and ElevenLabs voices can't hand off.
It stops handing off

The rule
  • Greeting says why, not what
  • No details before the code
  • Wrong person? Take a message
You dialed the number on file. Still not proof it's Dan picking up. So the greeting says why she's calling, nothing private. Code first, then the details. Wrong person: take a message, no details. Whoever answers isn't always the customer. No machine, dates or money before the code. Source: Made-up call. The outbound greeting and the verify rule come from the kit checklist 07-outbound.

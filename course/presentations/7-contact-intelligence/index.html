Added to your prompt
## Caller Intelligence

You have access to a CALLER CONTEXT section above this prompt containing:
- Caller's name and company
- Number of previous calls and last call date
- Recent conversation topics
- Tags (e.g., VIP, Hot Lead)
- Notes from previous interactions
- Upcoming scheduled appointments

Use this information naturally throughout the call. Don't read it back robotically: weave it into conversation.

The inbound webhook · shape

What we send. What you send back.

Leadlock sends
POST https://your-crm.example.com/leadlock/inbound
X-Leadlock-Signature: sha256=<hmac>

{
  "event": "call_inbound",
  "call_inbound": {
    "from_number": "+15555550142",
    "to_number": "+15555550100",
    "agent_id": "...",
    "call_id": "CA...",
    "timestamp": "2026-10-23T14:02:11Z"
  }
}
You reply (within the timeout)
{
  "dynamic_variables": {
    "caller_name": "Sarah",
    "last_job": "Water heater install",
    "balance_due": "$0"
  }
}

// or turn the call away:
{ "reject": true,
  "reject_message": "We're closed today." }
Then in the prompt: Hi {{caller_name}}, calling about the {{last_job}}?
Webhook variables win over Contact Intelligence ones. Placeholder numbers.
Leadlock.ai
This is all Leadlock sends: who's calling, which number they called, which agent. You answer with any variables you want. Or reject, and it reads your message and hangs up. Check the signature header on your side. There's a Test button on the agent too.
After the call

Then the data flows out.

The call ends, Leadlock writes the summary, then posts the result to your agent webhook and your sub-account webhook.
Fires once per call, as call.completed, or recording.ready when recording is on. Test calls are skipped.
Call ends. Leadlock writes the summary. Then it posts the result out: transcript, summary, outcome. Two places it can go. Next slide is the difference.

Agent webhook = one agent's calls; sub-account webhook = calls, recordings, texts, bookings, sequences. Both signed.
Leadlock.ai
Agent level: lives on one agent, fires only for that agent's calls. Sub-account level: Settings, Webhooks. Every agent, plus texts and bookings. Rule of thumb: one agent into a GoHighLevel workflow, agent level. Everything into n8n, sub-account level.

GoHighLevel vs any other CRM

Same agent, two ways to connect.

GoHighLevelAny CRM with an API
Context inBuilt in: contact, calendar, pipelineInbound webhook, often via n8n
Data outContact sync, notes, conversation syncPost-call webhook or n8n
WorkflowsLeadlock actions inside GoHighLevelYour own automation
Leadlock's memoryCalls, texts and profileCalls
GoHighLevel works out of the box. Anything with an API can be connected through the webhooks.
GoHighLevel works out of the box. Context in, data out, workflows. Anything else with an API can be connected: inbound webhook in, post-call webhook out. n8n is the easy middle. Leadlock's call memory works on both. Texts and the contact profile come with GoHighLevel.

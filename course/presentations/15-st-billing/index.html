Only what's on file.
n8n decides the channel, not the agent. A2P number: it texts. No A2P yet: it emails. Both only to what's on file. If a caller says send it to this other number: no. That's how money gets stolen. With A2P, carriers deliver the text and the caller taps and pays. Email: same link, same rules. Never to a number or email the caller reads out. Source: Kit install-support-team: n8n sends the link only to the email or phone on file; by text when an A2P number is set, else email.

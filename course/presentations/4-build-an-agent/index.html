The prompt

Shorter wins.

Every line is something the agent thinks about before it talks.
Same 39-field intake agent, prompt length
Written the old way
8,000 chars

3,700 chars
Fewer rules. Faster answers, fewer mistakes.
Leadlock agent build notes: a 39-field legal intake, about 8,000 chars written for older realtime models vs 3,700 on Grok think-fast.
Newer voice models need less hand-holding. Old-style prompts are full of patches. They cause bugs. Same job, less than half the words.

Five rules

Rules that save you hours.

  • Say what to do. Put every ‘never’ in Guardrails.
  • Intent plus the exception, not ‘always’ and ‘never’. It takes them literally.
  • Don't write the greeting into the prompt. It already speaks it on connect.
  • Every {{variable}} needs a default, or it gets read out loud.
  • Bad test call? Find the line that caused it. Remove it before adding anything.
Leadlock.ai
Each one came from a real broken agent. 'Never hang up with blanks' made an agent refuse to hang up. Rule 5 is the big one.

Low = on script

Same answer every time. Good for booking and intake.

High = more varied

Sounds looser. Drifts more. Turn it down if it goes off script.

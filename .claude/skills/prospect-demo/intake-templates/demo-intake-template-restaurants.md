# Demo Intake Template — Restaurants

Reusable email template for gathering info from restaurant prospects before building a voice agent demo. Tuned for the reality of restaurant calls: reservations, takeout, FAQs, and rescuing the calls a host misses on a busy Friday night.

---

**Subject:** Quick info to build your restaurant's voice agent demo

Hey [Name],

Great talking today. To build a demo that sounds like it actually works at [Restaurant Name] — knows the menu, handles a reservation, sounds like your host on a good night — I need a few things. The more detail here, the sharper the demo.

**What I need:**

**1. The basics**
- Restaurant name(s) — list every location if you have more than one
- Cuisine / concept (e.g., "wood-fired Neapolitan pizza," "modern Mexican," "neighborhood gastropub")
- Vibe: fine dining / upscale casual / casual / fast casual / bar + grill / family
- Website + Instagram

**2. What should the agent handle on a call?** (Pick all that apply)
- Take reservations
- Take takeout / pickup orders
- Answer FAQs (hours, location, parking, dress code, kids, dogs on patio, BYOB, etc.)
- Handle private events / large parties / catering inquiries
- Take a message and text the manager
- Transfer to a human (host stand, manager, events coordinator)
- Something else?

**3. Reservations — how do you take them today?**
- System: OpenTable / Resy / Tock / SevenRooms / Yelp / phone-only / other
- Party size: smallest and largest the agent can book without escalating (e.g., 2–8 books direct, 9+ transfers to events)
- Days/times you take reservations vs. walk-in only
- Any deposit, credit-card hold, or cancellation policy the agent should mention
- Special requests you handle: birthdays, anniversaries, allergies, high chairs, accessible seating

**4. Takeout / pickup orders** (skip if you don't take phone orders)
- Do you want the agent to take full orders, or just route to your online ordering link?
- POS / ordering platform: Toast / Square / ChowNow / Olo / other
- Pickup window / lead time (e.g., "20 min weekdays, 35 min Fri–Sat")
- Payment: take card over the phone, or pay-at-pickup?

**5. Top 10 questions your phone actually gets — with the answers you'd want the agent to give**
Don't overthink the wording, rough answers are fine. Examples:
- "Are you open tonight?" → "Yes, we're open 5–10 tonight, kitchen closes at 9:30."
- "Do you take walk-ins?" → "We do, but Friday and Saturday after 6 we recommend a reservation."
- "Is there a kids menu?" → "Yes, $12, includes a drink and a side."
- "Do you have gluten-free options?" → "Most of our pasta and pizza can be made GF, $3 upcharge."
- "Where do I park?" → "Free lot behind the building off Maple Ave."

**6. Allergens, dietary, and "is this safe for my kid" calls**
These calls are high-stakes. How do you want the agent to handle them?
- (A) Answer with general info, recommend they tell the server on arrival
- (B) Answer specific allergen questions (gluten, nuts, dairy, shellfish) from a list you give me
- (C) Always transfer allergy questions to a manager

**7. When should the agent transfer to a human?**
(e.g., parties of 10+, complaints, lost-and-found, press inquiries, large catering, anything outside its lane)

**8. Private events, catering, large parties** (skip if not applicable)
- Minimum size and spend
- Who handles event inquiries (name, email, phone)
- Should the agent collect details and email/text them, or transfer live?

**9. Hours, holidays, and the weird stuff**
- Regular hours by day
- Happy hour windows
- Brunch only on weekends?
- Any upcoming holiday closures or special hours the agent should know about

**10. Agent personality**
- Name (consider matching your restaurant vibe — "Marco" for an Italian spot, "Frankie" for a casual neighborhood place)
- Tone: warm + welcoming / refined + composed / energetic + fun / dry + cool
- Male or female voice
- Accent preference (American neutral / regional / Italian / Spanish-fluent / other)

**11. Languages**
Should the agent handle Spanish callers? Any other languages? (We can build a bilingual agent that switches automatically.)

**12. Existing call recordings from your host stand** ⭐
This is the biggest unlock. If you can grab 3–5 recordings of real reservation calls, takeout calls, or FAQ calls — even phone audio held up to a recorder — the agent will sound 10x more like your team. Anonymize anything sensitive, I just need the conversation flow.

**13. Anything else I should know**
House rules, weird quirks, things the host always has to explain, the joke about the parking lot — anything that makes your place yours.

Just reply to this email or drop it in a Google Doc — whatever's easier. If you can attach a current menu PDF and a screenshot of your reservation system's availability page, even better.

Talk soon,
[Your name]

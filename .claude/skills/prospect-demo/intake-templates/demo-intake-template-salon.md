# Demo Intake Template — Salons, Barbers & Beauty

Reusable email template for hair salons, barbershops, nail salons, lash studios, and multi-service beauty shops (non-medical). For med spa / aesthetic clinics, use the med-spa template instead — different guardrails.

Tuned for the reality of salon calls: stylist-specific bookings, walk-in vs. appointment, the "how much for [service]" question, and reschedules.

---

**Subject:** Quick info to build [Salon]'s voice agent demo

Hey [Name],

Great talking. To build a demo that sounds like your front desk — booking with the right stylist, answering pricing questions, handling reschedules — I need a few things.

**What I need:**

**1. The basics**
- Salon / shop name + locations
- Services: hair / barber / nails / lash / brow / waxing / skincare (non-medical) / multi-service
- Vibe: high-end / neighborhood / chain / men's-only / specialty (curly hair, extensions, etc.)
- Website + Instagram (Instagram matters)

**2. Stylists / techs — names, specialties, levels**
Some clients call asking for a specific person by name. The agent needs to know who's who.
- Roster: name → specialties (cut, color, extensions, etc.) → tier (junior / senior / master)
- Days each works (or "varies, check the system")
- Anyone not taking new clients?

**3. What should the agent handle?** (Pick all that apply)
- Book appointments (specific stylist or any-available)
- Service / pricing questions
- Reschedule / cancel
- New client onboarding (consultation, patch test, deposit)
- Walk-in availability
- Product questions / orders
- Transfer to front desk
- Take a message

**4. STYLIST-SPECIFIC BOOKING — the dynamic**
- "Can I get in with [stylist] this week?" — agent looks up their calendar
- "What's [stylist]'s next opening?" — agent answers directly
- "I want whoever has time" — does agent assign or ask preference (junior vs. senior, gender, etc.)?
- Stylist tier pricing — how should the agent quote? (e.g., "with our master stylist it's $120, with our senior it's $90")

**5. Service + pricing menu**
Top 10–15 services with prices and durations. Examples:
- Women's haircut: $65 (junior) / $85 (senior) / $110 (master), 60 min
- Men's haircut: $35–55, 30 min
- Color (single process): $90+
- Full highlight: $180+
- Balayage: $250+
- Gloss: $50
- Lash full set: $200, lash fill $90
- Brow wax: $25
- Manicure: $35, gel mani $50

Don't overthink the wording — rough is fine.

**6. New client first appointment**
- Consultation required for color services? In-person or phone?
- Patch test policy (24/48 hours before for chemicals)
- New client deposit / hold-card policy?
- First-time discount or new-client special?
- Any forms to fill out before the appointment?

**7. Booking system**
- Vagaro / Boulevard / Square Appointments / Booksy / GlossGenius / Phorest / Mindbody / phone-only
- Stylist-specific booking rules
- Buffer time between appointments
- Online booking enabled? (push clients there or take on phone?)

**8. Top FAQs**
- "Do you take walk-ins?"
- "How much for [service]?"
- "Do you do [specialty — extensions, balayage, men's hair, kids, curly hair]?"
- "What products do you use? / Do you carry [brand]?"
- "How long will it take?"
- "Do you have parking?"
- "Do you accept tips on the card?"
- "Are you taking new clients?"

**9. Cancellation / no-show policy**
- Notice required? (24h, 48h)
- Cancellation fee?
- No-show fee or stored-card charge?
- Should the agent enforce ("I'm sorry, since it's less than 24 hours, there'll be a $X fee") or always escalate?

**10. When to transfer to a human?**
(Color corrections from another salon, complaints about a previous service, refund requests, large bridal / event party bookings, refunds)

**11. Personality** — match the vibe
- Name (warm, friendly names — Sophia, Ava, Maya)
- Tone:
  - High-end salon — refined, composed, knowledgeable
  - Neighborhood salon — warm, friendly, casual
  - Barbershop — direct, friendly, a little casual
- Voice — usually female for salons, can go either way for barbershops
- Accent

**12. Languages**
Spanish is huge in many salon markets. Bilingual agent?

**13. Existing call recordings** ⭐
3–5 real front-desk calls — booking, reschedule, pricing question, walk-in — gold for tuning the demo.

**14. Send if available**
- Full service menu PDF with pricing
- Stylist roster + bios
- Cancellation policy
- Any active promo / first-time client offer

Just reply or drop it in a Google Doc — whatever's easier.

Talk soon,
[Your name]

# Demo Intake Template — Real Estate

Reusable email template for real estate agents, teams, and brokerages. Tuned for the reality of real estate calls: agents physically can't pick up (in showings, in closings, driving), leads go cold in minutes, and a single missed buyer-side call can be $10k+ in lost commission.

---

**Subject:** Quick info to build [Agent / Team]'s voice agent demo

Hey [Name],

Great talking. To build a demo that sounds like your team's inside sales agent on a Saturday afternoon — capturing buyer leads, fielding "saw your sign" calls, helping sellers — I need a few things. The more detail here, the sharper the demo.

**What I need:**

**1. The basics**
- Agent / team / brokerage name
- Markets you serve (city, neighborhoods, zip codes)
- Specialty: first-time buyers / luxury / investors / new construction / 55+ / commercial / mixed
- Website + IDX site
- Solo agent or team? If team, how many agents and how are leads split?

**2. What should the agent handle?** (Pick all that apply)
- Buyer inquiries from listings (Zillow, Realtor.com, sign calls)
- Seller inquiries / "what's my home worth"
- Showing requests
- Status updates for active clients (under contract, closing soon)
- "Is the property at [address] still available?"
- General brokerage info
- Transfer to an agent
- Take a message

**3. BUYER QUALIFYING — what should the agent collect?** 🏠
The big filter is whether they're talking to a lender. Suggested flow:
- Pre-approved with a lender? (Yes / no / "what's that?")
- Cash or financed?
- Price range
- Timeline — buying in 30 days, 90 days, "just looking"?
- Working with another agent already?
- Areas of interest
- Bedrooms / property type

What's a "hot lead" worth a live transfer? (e.g., pre-approved + ready to see this week)

**4. SELLER QUALIFYING — the unicorn call** 💰
"What's my home worth?" is the call you don't want to miss. What should the agent capture?
- Property address (so you can pull comps)
- Timeline to sell
- Working with another agent already?
- Reason for moving (don't push, but capture if volunteered)
- Best way to follow up (call, text, email)
- Schedule a CMA / listing consultation?

**5. Lead routing**
- Solo or team? Buyer specialists vs listing specialists?
- Routing rules: by neighborhood, by price range, by language, round robin?
- Live transfer criteria — when should the agent ring an agent's cell vs. take info and follow up?

**6. CRM + tools**
- CRM: Follow Up Boss / kvCORE / Lofty (Chime) / BoomTown / Sierra Interactive / Real Geeks / Top Producer / other
- Showing tools: ShowingTime / Showami / direct call
- Should the agent confirm a listing is still active? (MLS lookup, last-checked timestamp)

**7. Top FAQs**
- "Is the property at [address] still available?"
- "Can I see this house today / this weekend?"
- "What's the commission?" (or "do you charge buyers?" — post-NAR settlement)
- "Do you do VA / FHA / first-time buyer programs?"
- "Do you have any off-market / pocket listings?"
- "What's the school district like?" (be careful — fair housing implications)

**8. After-hours behavior**
Most real estate calls come 5pm–9pm and weekends. Should the agent:
- Live transfer to on-call agent
- Capture full intake, agent calls back first thing
- Hybrid based on lead score (preapproved buyer = transfer, tire kicker = capture)

**9. When to transfer immediately?**
(Pre-approved buyer ready to see today, motivated seller with timeline, current client urgent issue, referral from a known partner)

**10. Personality**
- Name
- Tone: knowledgeable + warm + NOT pushy (real estate has a sales-y reputation; lean opposite)
- Male or female
- Accent

**11. Languages**
Spanish-speaking buyers are a huge slice of many markets. Bilingual agent or transfer to a Spanish-speaking agent?

**12. Existing call recordings** ⭐
3–5 real calls — sign call, Zillow lead, seller inquiry, status update — gold for tuning the demo.

**13. Send if available**
- Buyer guide / seller guide
- Current listings link / IDX URL
- Pre-approval partners (preferred lenders to recommend)
- Any active campaigns (new construction, neighborhood-specific)

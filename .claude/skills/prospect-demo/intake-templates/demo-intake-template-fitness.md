# Demo Intake Template — Fitness Studios & Gyms

Reusable email template for boutique fitness studios, gyms, CrossFit boxes, yoga / pilates / barre studios, and personal training. Tuned for the reality of fitness calls: free trial conversion, class booking, membership freezes/cancels, and matching the agent's energy to the studio's vibe.

---

**Subject:** Quick info to build [Studio]'s voice agent demo

Hey [Name],

Great talking. To build a demo that sounds like your front desk on a Monday morning — converting trial leads, handling class bookings, fielding membership questions — I need a few things.

**What I need:**

**1. The basics**
- Studio / gym name + locations
- Type: gym / boutique fitness (yoga / pilates / barre / cycling / HIIT) / CrossFit / personal training / MMA / specialty
- Class-based, open gym, or hybrid?
- Vibe: high-energy + loud / calm + zen / community-focused / luxury / no-frills
- Website + Instagram (Instagram matters here)

**2. What should the agent handle?** (Pick all that apply)
- Free trial / first class booking
- Membership inquiries (pricing, what's included)
- Class schedule questions
- Existing member questions (cancel, freeze, billing dispute)
- Personal training inquiries
- Transfer to staff
- Take a message

**3. NEW LEAD CONVERSION — the money question** 💰
"How much is membership?" calls. What's your strategy?
- (A) Give pricing upfront, then push to free trial
- (B) Push to free trial first, pricing after they book
- (C) Hybrid — give starting price, immediately offer free trial
- (D) "I want to make sure we get you the right plan, can I get you in for a free class first?"

What's your free trial / intro offer? (1 free class, 1 week unlimited, $X for 2 weeks, etc.)

**4. Class booking system**
- Mindbody / ClubReady / Mariana Tek / Glofox / WellnessLiving / Zen Planner / Pike13 / phone-only
- Should the agent book directly into a specific class, or push them to download the app?
- Class size limits / waitlist handling
- New-member-only restrictions on certain classes (e.g., Level 1 only for first 4 classes)

**5. Membership tiers**
List your tiers with pricing. Examples:
- Drop-in: $25/class
- 4-pack: $80
- 8-pack: $150
- Unlimited monthly: $199
- Annual: $1,800
- Family / corporate / student / first responder discount?
- Initiation fee / contract length?

**6. Existing member handling**
What can the agent do vs. transfer?
- Freeze membership (criteria, fee, duration)
- Cancel membership (notice period, fee, "are you sure" flow)
- Billing dispute → always transfer?
- Class no-show / late cancel fees → can the agent waive once?
- Update payment method → push to app, or take card on call?

**7. Top FAQs**
- "How much is membership?"
- "Do you offer a free trial?"
- "What's your class schedule?"
- "Do I need experience for [class type]?"
- "Do you have childcare?" (gym specific)
- "Is there a contract?"
- "Can I freeze my membership?"
- "Do you offer personal training?"
- "What should I bring to my first class?"
- "Is there parking?"

**8. When to transfer to staff?**
(Cancellations if owner wants control, billing disputes, complaints, corporate / large group inquiries, injury / medical questions, refunds)

**9. Personality** — match the vibe
- Name
- Tone matching the studio:
  - Yoga / pilates / barre — calm, warm, grounded
  - CrossFit / HIIT / cycling — energetic, motivating, "let's go"
  - Personal training — knowledgeable, encouraging
  - Big-box gym — friendly, helpful, no pressure
- Male or female
- Accent

**10. Languages**
Spanish in many markets, especially big-box gyms.

**11. Existing front desk call recordings** ⭐
3–5 real calls — trial inquiry, class booking, freeze request, FAQ — gold for tuning the demo.

**12. Send if available**
- Class schedule (current week)
- Membership tier sheet
- Intro offer flyer
- Any active campaigns (New Year, summer prep, "30 days free")

Talk soon,
[Your name]

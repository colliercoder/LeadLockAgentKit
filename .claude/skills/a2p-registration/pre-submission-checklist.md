# Pre-Submission Checklist

Run **every** box before clicking Create. This is the gate that catches the typo, the missing link, and the required checkbox - the things that cause almost all rejections. It is faster than one rejection cycle.

## Website & pages (reviewers will visit these)
- [ ] Website URL in the field is **typo-free** and returns 200 directly (prefer `https://www.<domain>`, no redirect)
- [ ] Privacy Policy is **live and public** at the URL you entered (not behind a login)
- [ ] Privacy Policy includes the **mobile-data non-sharing** clause
- [ ] Terms of Service is **live and public** and includes the SMS section (opt-out, frequency, rates, support)
- [ ] `/sms-terms` proof page is **live** with a screenshot of the opt-in step
- [ ] Footer on the opt-in page shows **Privacy / Terms / SMS Terms** links

## Opt-in form (the #1 rejection source)
- [ ] Consent checkbox exists on the stated page
- [ ] Checkbox is **unchecked by default**
- [ ] Checkbox is **NOT required** to submit - verified by submitting the form without checking it
- [ ] Checkbox label starts with **"(Optional)"** and includes **"Consent is not required to ..."**
- [ ] Checkbox label includes: brand name, frequency, "Message & data rates may apply", **STOP**, **HELP**, Privacy link, Terms link

## Use case & description
- [ ] Use case **matches every message type** you actually send (no transactional content in a Marketing campaign)
- [ ] Campaign description states the message type explicitly (Marketing → "marketing messages only" + what is NOT sent)
- [ ] Description answers WHO sends, WHO receives, WHY

## Sample messages
- [ ] Between **2 and 5** samples
- [ ] **Brand name** appears in at least one (ideally all)
- [ ] At least one includes **"Reply STOP to opt out"**
- [ ] All URLs are **full-domain** and **resolve** (no 404)
- [ ] **No URL shorteners** (bit.ly, tinyurl) anywhere
- [ ] `[Brackets]` used for dynamic fields
- [ ] Samples match the registered use case
- [ ] No SHAFT / prohibited content

## Keywords & auto-replies
- [ ] Opt-out keywords include **STOP, STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT**
- [ ] Help keywords include **HELP, INFO**
- [ ] Opt-in, opt-out, and help confirmation messages are filled and identify the brand

## Content attributes
- [ ] "Embedded links" checked if any sample has a URL
- [ ] "Embedded phone numbers" checked **only** if a sample contains a phone number
- [ ] Lending / age-gated attributes are accurate (usually NO)

## Brand consistency
- [ ] Legal business name matches **IRS records exactly**
- [ ] EIN matches IRS exactly
- [ ] Same brand name appears in registration, website, and sample messages
- [ ] No PII in any campaign field

When all boxes are checked, submit.
